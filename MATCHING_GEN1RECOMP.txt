Mod release: v0.4.33 first-class Pokemon Crystal compatibility (retains v0.4.32 Kanto OPEN WORLD/WORLD OCEAN, v0.4.31 persistent sector preload, v0.4.30 UI text-size slider, v0.4.25 Pidgeotto flight-safe loop, and earlier announcer/voxel optimizations).
Checked against Gen1Recomp dev commit 0142468125cf97bb72cc0dcd242b6dc9cd31401b (2026-08-24).

Current Gen1Recomp defines Crystal as generation 2 with its own `crystal` engine lineage, cache prefix and save suffix. The manifest remains generation-scoped (`games = ["gen2"]`), which current ModTargets expands to Gold, Silver and Crystal.

v0.4.33 removes the remaining edition-hardcoded mobile picker route and gives persistent voxel meshes a per-edition namespace. Gold/Silver/Crystal can therefore share this mod install without fighting over same-name sector cache files.

The Gen-2 world/player/map modules remain the engine authority. Crystal's Chris/Kris sprite choice is not replaced by a hard-coded trainer asset; the voxel pose consumes the live `src.world.gen2.Player` sprite just like Gold/Silver.

No new privileged API is required beyond the current Gen-2 surfaces already used by this mod.
